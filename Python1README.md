Python To-Do List Application

Project Description

This is a simple console-based To-Do List application developed using Python. The program allows users to manage their daily tasks through a menu-driven interface.

Features

* Add a new task
* View all tasks
* Delete a task
* Update a task
* Mark a task as completed
* Handle invalid choices
* Exit the application

Technologies Used

* Python

Python Concepts Used

* Lists
* While Loop
* For Loop
* Conditional Statements
* Functions such as "len()" and "enumerate()"
* List methods such as "append()" and "pop()"
* User Input using "input()"

How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Run the Python file using Python.
